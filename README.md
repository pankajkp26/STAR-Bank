# Star Bank Management System

## About

This is a simple bank management system made using Python and Tkinter.

It allows the user to:

- Create a new bank account
- Login to an account
- Deposit money
- Withdraw money
- Check account balance
- Logout from the account

## Technologies Used

- Python
- Tkinter

## Features

### Create Account

The user enters:

- Name
- Initial deposit
- Password

The program generates a random account number.

### Login

The user logs in using:

- Name
- Account number
- Password

### Deposit

The user can add money to their account.

### Withdraw

The user can withdraw money if they have enough balance.

### Check Balance

The user can view their current account balance.

## How to Run

Make sure Python is installed on your computer.

Run the Python file:

```bash
python bank.py
```

Tkinter normally comes with Python.

## Note

This is a basic educational project.

The account data is stored only while the program is running. The data is lost when the program is closed.

This project is not intended for real banking use.
