# STAR Bank Management System

## About

This is a simple bank management system made using Python and Tkinter.

It enable the user to:

- Open a new bank account
- Sign in to an account
- Make a Deposit
- Withdraw Cash
- Check account balance
- Logout from the account

## Technologies Used

- Python
- Tkinter

## Features

### Make Account

The user enters:

- Name
- Initial deposit
- Password

The program generates a random account number.

### Login

The user logs in with:

- Name
- Account number
- Password

### Deposit

The user can top-up to his account.

### Withdraw

The user can withdraw money when they has sufficient balance.

### Balance Check

The user can see his  current balance of account.

## How to Run

Be sure that you have Python installed on your computer.

Run the Python file:

```bash
python bank.py
```

Tkinter normally comes with Python.

## Note

This is a basic educational project.

The account data is stored only while the program is running. The data is lost when the program is closed.

This project is not intended for real banking use.
